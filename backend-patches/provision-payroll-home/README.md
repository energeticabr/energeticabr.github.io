# Retorno ao menu após baixar uma provisão

O botão de início encerra a etapa opcional de vínculo com a folha quando a baixa do descritivo, todas as provisões selecionadas e os comprovantes já foram confirmados. O servidor envia diretamente o menu principal e limpa a bandeja temporária. Uma baixa em andamento continua protegida pelo diário de gravação.

A correção funciona pelo servidor compartilhado de Windows, Android e iOS. O instalador reaproveita o mesmo gate e backup da publicação de folha e atualiza exclusivamente o módulo de baixa por descritivo.

Para testar com uma cópia do backend, execute `BACKEND_ROOT=/caminho/backend python -B test_workflow.py`. Os testes usam dados fictícios e um diretório temporário para o estado da conversa.
